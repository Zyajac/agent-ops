# T006 — Fan-out / Fan-in

## Objective
Implement child-task creation, parent/child relationships, aggregation rule and fan-in guard.

## Constraints
Support `ALL_REQUIRED` initially. Every fan-out has a fan-in owner.

## Acceptance Criteria
Parent cannot complete before required children are ready; duplicate child completion is idempotent.

## Definition of Done
Fan-out/fan-in behavior is explicit and tested.
