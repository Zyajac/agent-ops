# T017 — Evaluation and cost

## Objective
Implement run metadata, token/cost tracking, basic evaluation dimensions and a metrics API.

## Constraints
Prefer integration with existing tracing systems instead of building a new tracing platform.

## Acceptance Criteria
Metrics are available by task/run; token/cost metadata is persisted where runtime provides it; no critical-path regression.

## Definition of Done
Evaluation and cost signals are queryable and tested.
