# T008 — Multica adapter

## Objective
Implement a narrow adapter for Issue, comment/mention, assignment and status projection. Normalize inbound events and send outbound updates.

## Constraints
Do not modify Multica core unless unavoidable. `@mention` is an adapter trigger, not the canonical protocol.

## Acceptance Criteria
Mocked contract tests pass; duplicate inbound events are safe; adapter failures are observable.

## Definition of Done
Multica remains the Work OS while Control Plane remains business-state authority.
