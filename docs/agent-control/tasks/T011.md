# T011 — Agent Runtime adapter

## Objective
Implement runtime-neutral `AgentRunner` and the first concrete adapter, using Agno if selected by configuration.

## Constraints
No LLM SDK types may leak into the domain layer.

## Acceptance Criteria
Mock run works; structured output is captured; runtime failures become normalized events.

## Definition of Done
Runtime can be replaced without redesigning Task, State, Events or Completion Guard.
