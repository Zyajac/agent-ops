# T001 — Repository bootstrap

## Objective
Set up service structure, configuration, health endpoint, PostgreSQL connection, migrations and testing baseline.

## Constraints
Architecture docs. Do not implement domain logic.

## Acceptance Criteria
Health endpoint works; DB connectivity works; tests run.

## Required workflow
1. Inspect repository and existing conventions.
2. Read `AGENTS.md`.
3. Read only the relevant docs and schemas.
4. Implement the minimum change.
5. Add/update automated tests.
6. Run tests.
7. Report changed files, tests and remaining risks.

## Definition of Done
- Acceptance criteria pass.
- Tests pass.
- No unrelated refactor.
- Integration boundaries are documented.
